# Data Engineering Mastery Path

A free, structured, module-wise training program on data engineering — entry
level to master level, with runnable Python/SQL code in every module and a
hands-on project at the end of each level. Taught from first principles:
`pandas` and SQLite in Level 1, then Airflow, Parquet/Arrow, dbt, Kafka
concepts, and Spark as the levels progress.

**Live site:** https://sigilipelli.github.io/data-engineering-mastery-path/

## Contents

- **Level 1 · Entry** — what data engineering is, Python & SQL for data work, ETL fundamentals, data modeling, file formats, batch processing, orchestration concepts, data quality/validation, and a simple ETL pipeline project
- **Level 2 · Intermediate** — advanced SQL, API ingestion, data warehousing, Airflow hands-on, partitioning & incremental loads, Parquet/Arrow, testing pipelines, streaming basics, dbt
- **Level 3 · Advanced** — Spark basics, advanced Airflow patterns, data lake architecture, streaming deep dive, governance & cataloging, CI/CD, performance tuning, cloud data warehouses, monitoring & alerting
- **Level 4 · Master** — enterprise platform architecture, real-time streaming at scale, data mesh, governance & compliance, cost optimization, MLOps overlap, platform teams, reliability engineering, career growth

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
